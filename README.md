# wizardry-clips
Wizardry-Replay é um sistema de replays voltado para pequenos negócios de aluguel de quadras esportivas. A plataforma automatiza a gravação de partidas, permitindo que atletas revivam lances, salvem melhores momentos e compartilhem jogadas nas redes sociais. É uma solução prática para engajar clientes e gerar receita extra.
